The release is one `.vlt` file. There is nothing to compile. The optional companion adds YouTube, skin sounds and framed-video hover controls.

The 1x main player is 300 × 298 pixels. **2x is on hold** and is not included in this release.

For developers: [Original resources](original/), [1x theme](vlc-1x/), [source inventory](provenance.json), [build notes](../../docs/DEVELOPMENT.md), [known differences](../../docs/PARITY.md). Original material keeps its owners’ rights.
